# Pi-specific skills

General agent skills live in the dotfiles repo. Put a skill here only when it depends on Pi-specific behavior, commands, extensions, package layout, or conventions.

Skill structure:

```text
skills/my-pi-skill/
└── SKILL.md
```

Each `SKILL.md` should include Agent Skills frontmatter:

```md
---
name: my-pi-skill
description: Use when ...
---
```
